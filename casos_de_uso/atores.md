# Casos de Uso - Truco Paulista

Este é um truco paulista individual, uma dupla contra outra. Existe o jogador,
e 3 bots. Os bots não são inteligentes, eles escolhem as cartas aleatoriamente.

## Atores

* **Jogador:** A pessoa 
* **Sistema:** faz o sorteio do baralho, cuida das regras, conta o placar e 
controla os três bots.

## Lista de casos de uso

* UC_001 - Iniciar partida
* UC_002 - Iniciar nova mão
* UC_003 - Jogar carta
* UC_004 - Pedir truco ou aumento
* UC_005 - Responder pedido de truco dos adversários
* UC_006 - Realizar jogada dos bots
* UC_007 - Responder pedido de truco pelos bots
* UC_008 - Resolver vaza
* UC_009 - Encerrar mão e atribuir pontos
* UC_010 - Decidir mão de onze
* UC_011 - Jogar mão de ferro
* UC_012 - Encerrar partida
